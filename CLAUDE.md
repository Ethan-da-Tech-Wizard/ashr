# ashr

Read `AGENTS.md` first. It holds the shared rules for every agent on this repo.

- Stack: Node 24, no npm packages, plain HTML/CSS/JS phone app, Claude Code `"type": "http"` hooks.
- After edits: run `npm test`. For UI changes, open `app/` at `/?demo=1` in a 390 px wide viewport.
- Anti-patterns: scraping terminal text to detect prompts, opening inbound ports, adding a framework.
